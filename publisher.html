OWNER-ONLY PUBLISHING

Publish & edit TruX stories.

TruX Technology is a single-author newsroom. Only NEWS: issues created by the repository owner (21-T4) are turned into public articles. Issues from anyone else are ignored by the automation.

Create a news post ↗ Edit existing posts ↗ Back to newsroom
PUBLISH FLOW
1.Sign into GitHub as 21-T4
2.Create or edit an issue titled “NEWS: your headline”
3.Write the story in the issue body (headings, lists, links and images work)
4.Optional: add a label to set the category
5.Automation publishes the page, feed, sitemap and RSS
6.Close or delete the issue to unpublish
